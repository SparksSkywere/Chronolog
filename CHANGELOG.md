## [1.0.0] — 2026-10-25

### Added
- **Chronolog Modern** for Windows 10/11 (self-contained) and **Chronolog Classic** for Windows 7 SP1, 8, and 8.1 (.NET Framework 4.8).
- Journals with dated entries: create, search, edit, delete, and attach files.
- **File → Storage Location…** so the library can live on a sync folder and follow you between PCs.
- Inno Setup installers with Start Menu and Desktop shortcuts under Skywere Industries.
